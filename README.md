# PIPELINE1 · Erste Ebene · ANKER / SCAN

Zweck:
PIPELINE1 bildet die erste Ebene der Vier-Ebenen-Pipeline ab:
SCAN → OCR → NET/NC → OUTPUT.

Ebene 1 ist der ANKER:
- Stabilisation
- Eingang
- EAR-Achse
- Kamera-Scan
- Rohdatenaufnahme

Axiome:
K(t) = 1 / (1 - t)
Φ(t) = φ∞ · K(t)
DualTransport: io = +Δx·K(t), oi = -Δx·K(t)

Struktur:
Ebene 1: SCAN / ANKER / EAR
Ebene 2: OCR
Ebene 3: NET/NC
Ebene 4: OUTPUT/OI

Kompatibilität:
- IO / OI
- TRANS-WARB
- WARB KANAL
- Highway
- Slalom
- Axiom-Dreieck-6
- Modul-IO-8
